# VET 360° — Veterinary Learning Hub

เว็บแอปเพื่อการศึกษา รองรับมือถือและติดตั้งแบบ PWA ได้เมื่อเผยแพร่ผ่าน HTTPS (เช่น GitHub Pages)

## วิธีเปิดใช้งาน
1. แตกไฟล์ ZIP
2. อัปโหลดไฟล์และโฟลเดอร์ทั้งหมดเข้า repository ของ GitHub Pages (คงโครงสร้างเดิม)
3. ไปที่ Settings → Pages แล้วเลือก branch/folder ที่ใช้เผยแพร่
4. เปิด URL เว็บไซต์ด้วย Safari/Chrome
5. iPhone: เปิดเว็บใน Safari → Share → Add to Home Screen

## ความสามารถในรุ่นนี้
- หน้าหลักและหมวดบทเรียน
- บทเรียนเริ่มต้น 10 บท: กายวิภาค ศัลยกรรม/เย็บแผล อุปกรณ์ เภสัชวิทยา CBC การเก็บเลือด การตรวจร่างกาย และสัตว์หลายชนิด
- คลังตัวย่อพร้อมคำอ่านไทย
- รายการอุปกรณ์และการใช้งานเบื้องต้น
- สรุปงานแล็บและความปลอดภัย
- แบบทดสอบพร้อมเฉลย
- บันทึกบทเรียนและความคืบหน้าด้วย localStorage
- ลงทะเบียน/เข้าสู่ระบบแบบสาธิต (เก็บเฉพาะชื่อและอีเมลในเครื่อง ไม่ใช่ระบบบัญชีจริง)
- PWA manifest และ service worker สำหรับ cache ไฟล์หลัก

## ข้อจำกัดที่ต้องทราบ
- นี่คือ **รุ่นเริ่มต้นที่ใช้งานได้** ไม่ใช่ฐานความรู้ครบทุกชนิดสัตว์ และยังไม่มีภาพถ่าย/แผนภาพกายวิภาคเฉพาะอวัยวะในทุกบท
- ระบบบัญชีเป็นเพียงตัวอย่างฝั่งอุปกรณ์ ไม่ปลอดภัยสำหรับบัญชีผู้ใช้จริง และไม่มีการซิงก์ข้ามอุปกรณ์
- หากต้องการสมาชิกจริง ต้องเชื่อม Firebase หรือ Supabase Auth พร้อมฐานข้อมูลและกฎความปลอดภัย
- เนื้อหาเรื่องยา ขนาดยา การดมยาสลบ การผ่าตัด และเย็บแผลใช้เพื่อการเรียนเท่านั้น ห้ามใช้แทนคำสั่งสัตวแพทย์หรือ SOP ของสถานพยาบาล
- ค่าตรวจทางห้องปฏิบัติการต้องเทียบช่วงอ้างอิงเฉพาะชนิดสัตว์ อายุ วิธีตรวจ และห้องปฏิบัติการ

## โครงสร้าง
- `index.html` หน้าจอและโครงสร้าง
- `styles.css` รูปแบบและ responsive layout
- `data.js` ข้อมูลบทเรียน/ตัวย่อ/อุปกรณ์/แบบทดสอบ
- `app.js` การทำงานและการบันทึกความคืบหน้า
- `manifest.webmanifest`, `sw.js` สำหรับ PWA
- `assets/` ไอคอนแอป
